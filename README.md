# 组会周报仓库（模板）

每周一个目录，放当周的组会 PPT 和自己的进展说明。看板会自动汇总，老师打开网页就能看到每人的进度和 PPT。

## 目录规范

```
2026-W46/
├── 组会汇报-你的名字-2026-W46.pptx   # 或 .pdf / .key / .ppt
└── README.md                        # 本周进展（老师主要看这个）
```

- 目录名必须是 `YYYY-Wxx`，`W` 要大写、两位数，例如 `2026-W46`
- 每周新建一个目录，不要往旧目录里覆盖新内容（会算成补交）
- 截止时间默认每周日 23:59，超时看板标「迟交」

## 怎么上传（不用装 git）

1. 在本仓库页面点 **Add file → Upload files**
2. 把本地 `2026-W46` 整个文件夹拖进去
3. 底下点 **Commit changes**

## README.md 怎么写

```markdown
## 本周做了什么
- 完成数据清洗，样本量扩到 15 万

## 遇到的问题
- 小样本梯度爆炸，正在试 clipping

## 下周计划
- 补实验，接入主流程
```

三五行就够，重点是让老师一眼看出这周推进到哪。
